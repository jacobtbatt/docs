## Welcome

Welcome to the new Thnks API Documentation.  As a Thnks Admin, you have access to many different automation features that are now being made public!

## Headers

All API endpoints are authenticated using an Authorization API token. This token is tied to the sender’s account. Follow the instructions found in the [Get Started - Request an API Key](https://docs.thnks.com/get-started/request) section.

While "Authorization" and "Content-Type" are both **required** headers, you can **optionally** pass an idempotency key in the header block. This will prevent repeat sends (or Creation of a new Redemption URL) under the same key for 3 hours.

```json
"headers": [
  {
    "Authorization": "<api_key>",
    "Content-Type": "application/json",
    "Idempotency-key": "<optional header field>"
  }
]
```
